Technical & Security Architecture Overview

For Developers, Auditors & Security Researchers · Version 3.0.0

⚙️ Core Engineering Architecture Stack:
• Database: SQLite with AES-256 SQLCipher encryption at rest
• Key Derivation: PBKDF2 via FlutterSecureStorage hardware keystore
• Vector Search: TurboVec compiled C++/Rust FFI SIMD extensions (134.7M ops/sec)
• AI Engine: On-device local LLM & Sarvam AI / Arya India Cloud API fallback
• Vision OCR: Google ML Kit Latin & Devanagari text recognition

1. Privacy-Preserving Notification Listener Service

Instead of requesting invasive READ_SMS permissions, VITT implements a custom Android NotificationListenerService. Incoming status bar notifications from recognized banking apps (GPay, Paytm, PhonePe, HDFC, SBI, CRED) are intercepted, parsed via regex matching, and logged locally. Unrelated notifications (WhatsApp, Telegram) are ignored instantly on-device.

2. On-Device RAG & TurboVec Vector SIMD Engine

VITT embeds transaction records into 256-dimensional vector representations. Using compiled native Rust FFI extensions (libturbovec.so), vector cosine similarity searches run at over 134 Million operations/sec directly on device hardware with sub-3ms latency, enabling natural language transaction queries without cloud vector database costs.

3. Hardware-Backed Encryption at Rest

All local database files (vitt.db) are encrypted using sqflite_sqlcipher. The 256-bit encryption key is dynamically generated on first launch and stored securely in Android KeyStore via FlutterSecureStorage.
