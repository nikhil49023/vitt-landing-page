VITT Privacy Policy

Last Updated: July 30, 2026 · Version 3.0.0 · Compliance: DPDP Act 2023 & RBI Guidelines

🔒 Summary of Core Privacy Guarantees:
  • Zero READ_SMS permissions requested. We never read your private SMS inbox.
  • All transaction data is stored 100% locally in an AES-256 SQLCipher encrypted SQLite database.
  • Zero financial data, bank account details, or transaction histories are uploaded to cloud servers.

1. Compliance with Digital Personal Data Protection (DPDP) Act 2023

Under India's Digital Personal Data Protection Act, 2023 (DPDP Act), VITT operates as a Data Fiduciary enforcing data minimization, explicit consent, and local-first data processing. Financial records remain exclusively under user custody on physical device hardware.

2. Information Collection & Processing

  • Transaction Data (Notification Listener):** Extracted locally from banking app notifications (Google Pay, Paytm, PhonePe, HDFC, ICICI, SBI). Stored in local AES-256 SQLite (`vitt.db`). Never transmitted externally.
  • Authentication Data:** Google Sign-In Name and Email via Firebase Authentication for identity verification.
  • Crash Data:** Anonymous stack traces via Firebase Crashlytics to monitor app stability.

3. Prominent Disclosure for Notification Listener Access

Notification Access is **disabled by default**. Before requesting system settings access, VITT presents an explicit prominent disclosure explaining that notification access is used solely to parse financial transactions and automatically excludes personal chat apps (WhatsApp, Instagram, Telegram).

4. Data Erasure & Withdrawal of Consent

You can revoke notification access at any time via Android System Settings. To permanently delete all stored data, navigate to Settings → Delete My Account in the VITT app, which purges the local SQLite database and Firebase auth records.
