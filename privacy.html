VITT Privacy Policy

Last Updated: July 30, 2026 · Version 3.0.0 · Compliance: DPDP Act 2023 & RBI Guidelines

🔒 Core Privacy Guarantees:
  • Zero READ_SMS Permissions Requested: We never read or access your private SMS inbox.
  • On-Device Encryption: All transaction records are stored exclusively in an AES-256 SQLCipher encrypted SQLite database on your physical device hardware.
  • Zero Telemetry: No financial data, account numbers, or transaction histories are uploaded to cloud servers.

1. Compliance with Digital Personal Data Protection (DPDP) Act 2023

In accordance with India's Digital Personal Data Protection Act, 2023 (DPDP Act), VITT operates as a Data Fiduciary enforcing data minimization, explicit consent, and local-first processing. All financial records remain under exclusive user control on your physical device hardware.

2. Information Collection & Processing

  • Transaction Data (Notification Listener): Extracted locally from banking app notifications (Google Pay, Paytm, PhonePe, HDFC, ICICI, SBI, CRED). Stored in encrypted local SQLite (`vitt.db`). Never transmitted to external servers.
  • Authentication Data: Google Sign-In Name and Email via Firebase Authentication for identity verification.
  • Crash Reporting: Anonymous stack traces via Firebase Crashlytics to monitor app stability.

3. Prominent Disclosure for Notification Listener Access

Notification Access is disabled by default upon installation. Before directing users to Android System Settings, VITT presents an explicit prominent disclosure explaining that notification access is used solely to parse financial transactions and automatically excludes personal chat applications (WhatsApp, Instagram, Telegram).

4. Data Erasure & Withdrawal of Consent

You can revoke Notification Access at any time via Android System Settings. To permanently delete all stored data, navigate to Settings → Delete My Account in the VITT app, which purges the local SQLite database and Firebase authentication records instantly.
